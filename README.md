# PSou 盘搜 · 网盘搜索

> 一个聚合公开网盘分享链接的搜索服务，支持夸克、百度、UC、迅雷。

在线使用：**https://psou.xyz**

## 功能

- 关键词搜索：片名、剧名、课程、电子书、资料
- 多平台聚合：夸克 / 百度 / UC / 迅雷
- 更新时间与失效状态展示
- 深度搜索：常规结果不足时实时补充
- 资源库：按电影、剧集、综艺等分类浏览
- 免登录、免费使用
- 移动端适配

## 技术栈

| 层 | 技术 |
|---|---|
| Web | PHP 8.2 + Nginx |
| 数据库 | MySQL 5.7 |
| 搜索 | 快照 + 缓存 + 本地索引 + 上游聚合 |
| 异步 | 独立 worker 处理转存任务 |
| 前端 | 原生 JS + 流式 NDJSON |

## 搜索流程

```text
用户输入关键词
  → 快照（毫秒级）
  → 结果缓存
  → 本地索引
  → 上游接口补充
  → 流式返回，先到先展示
```

## 设计原则

1. **不存储文件**：只聚合公开分享链接
2. **不保证永久有效**：网盘分享可能被取消或屏蔽
3. **版权归原作者**：请支持正版，不要商用
4. **失效可反馈**：遇到失效链接可以换平台或换关键词
